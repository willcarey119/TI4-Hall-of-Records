# V1.1 Human Validation Walkthrough

**Created:** 2026-04-29 (post-v1.08 deploy)
**Live URL:** https://ti4-hall-of-records-da562.web.app
**Goal:** Surface bugs, data errors, and UX issues across the entire app — feed them into the V1.1 implementation plan.

---

## How to use this document

This is a **two-pass audit**:

1. **Pass 1 — Static views sweep.** ~30 min. Walk through the views that don't depend on a specific game (HomePage, MetaDashboard tabs, AgendaPage, Upload UI). One row per view.
2. **Pass 2 — Per-game deep dive.** ~20 min × 7 games = ~2.5 hrs (split across days as you like). For each game, walk all 7 game-detail sections plus a "ground truth match" check.

For each row, fill the same four columns:

| Column | What to capture |
|---|---|
| **Renders OK?** | `Y` if it loads + displays without obvious breakage. `N` + note if blank screen, console error, broken layout. |
| **Numbers right?** | `Y` if the numbers match the actual game outcome. `N` + what's wrong if any value is suspect. Use `?` if you can't verify. |
| **UX issues** | Free-form list of layout, typography, mobile, interaction, color, spacing complaints. Be specific (which element, what's wrong, where). |
| **Ideas** | Optional — improvement suggestions you want to remember. **Note:** new analytics views go to V1.2+ backlog, not V1.1. |

After each section, there's a **"Discovered (free-form)"** block — that's your space for anything that doesn't fit the columns: questions, observations, "this thing I clicked did something weird," etc.

When done, ping me and I'll compile findings into the V1.1 implementation plan.
